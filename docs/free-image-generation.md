# 生图免费配置

在服务实际加载的 YAML 配置中，将下面字段合并到已有 `AmountConfig` 节点，然后重启服务。不要创建重复的 `AmountConfig` 节点。

```yaml
AmountConfig:
  FreeImageGeneration: true
```

这是服务级配置，对该服务的所有项目生效。默认 `false`（省略字段也为 false），不会自动修改现有部署配置。配置通过启动时加载生效，不是数据库动态配置。

## 开启后的行为

| 入口 | 规则 |
| --- | --- |
| 普通图像工作流、图像工具提交 | 所有计价规则执行后，将实际费用归零，不检查或扣减积分余额 |
| 模型直连生图 | 按服务端确认的模型直连模式识别为图片，不依赖虚拟分类存在于数据库 |
| 图片 → 视频组合任务 | 图片步骤实际费用及其任务记录为 0；视频步骤仍按现有规则收费 |
| 历史失败图像任务重试 | 根据任务保存的 `WorkflowType=WORKFLOW_KIND_TYPE_IMAGE` 免除本次费用；本次费用记录更新为 0，扣费记录为空 |
| 视频及非图像任务 | 收费规则不变 |

免费生图不等于免会员门槛：`is_vip_tool` 工具的会员校验仍保留。鉴权、任务参数校验、队列、并发和重试资格校验也继续生效。

普通工作流以服务端分类数据为准；分类缺失、查询失败或无法识别为图片时不免除费用，应修复分类数据。历史任务重试使用任务保存的类型，不根据名称或客户端参数猜测。

开启开关不会追溯退还此前已扣除的积分，不会修改正在执行的任务；已有任务失败的退款仍由原退款流程处理。

## 关闭后的行为

设置 `FreeImageGeneration: false` 后重启。新任务恢复原积分计价，会员图像免积分权益继续保留；模型直连图片同样能正确应用会员免积分。

重试仍基于任务保存的实际费用：历史付费任务在开关关闭时按原费用重试；已经免费创建或免费重试并保存为 0 的任务，后续重试仍为 0，不重新计算价格。

前端列表中的模型/工具基础积分配置不随开关自动改写；本配置改变的是提交和重试时实际扣款。客户端隐藏扣费展示时无需调整基础价格配置。

## 验证

```sh
go test ./conf ./internal/service/credit ./internal/api ./internal/service
```

联调时使用无积分普通用户验证新建图像任务和历史图像重试可提交；组合任务应只扣视频费用。另行确认 VIP 工具仍要求会员，视频余额不足仍被拒绝。
